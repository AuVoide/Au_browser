## 🚀 Overview
**AuVoide Flow** is not just a browser interface; it’s a **Neural Workspace**. It bridges the gap between traditional web browsing and artificial intelligence. Powered by the **Llama-3.3-70B** engine, it allows users to interact with the web through a smart, context-aware AI sidebar.

> "Stop just searching. Start flowing with information."

---

## ✨ Cutting-Edge Features

### 🧠 Neural AI Integration
* **Contextual Intelligence:** Chat with an AI that understands the web environment.
* **One-Touch AI Actions:**
    * 📝 **Summarize:** Condense long articles into key points instantly.
    * 💡 **Explain:** Simplify complex topics with a single click.
    * 💻 **Code:** Generate snippets or debug logic based on web content.
    * 🌍 **Translate:** Seamlessly bridge language gaps across the internet.

### 🎨 Premium Design Language
* **Glassmorphism 2.0:** A stunning, transparent interface using advanced CSS3 backdrop filters.
* **Reactive Sidebar:** A dedicated space for AI interactions that doesn't interrupt your browsing flow.
* **Hardware Accelerated:** Smooth animations and transitions built with zero-dependency Vanilla JS.

### ⚡ Performance Core
* **Ultra-Lightweight:** No heavy frameworks (React/Vue). Just raw, optimized JavaScript.
* **Groq API Infrastructure:** Experience lightning-fast AI inference with Llama-3.3.

## ⚙️ Installation & Setup

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/AuVoide/flow-browser.git](https://github.com/AuVoide/flow-browser.git)
    ```
2.  **Insert API Key:**
    Open `index.html` and locate the `GROQ` constant. Replace it with your API key:
    ```javascript
    const GROQ = "your_groq_api_key_here";
    ```
3.  **Boot System:**
    Launch `index.html` in any modern web browser (Chrome, Brave, or Edge recommended).
